# IntelliClaim AI — Frontend

React 19 + Vite frontend for the IntelliClaim AI insurance document intelligence platform.

## Stack

- React 19.2.7 + Vite 8
- React Router 7
- Recharts (analytics charts)
- Lucide React (icons)
- Axios (API client)
- ESLint 10, Vitest 4 + React Testing Library (tooling)

## Pages

| Route | Page | Description |
|---|---|---|
| `/` | Dashboard | Claim statistics, 30-day trend, average risk score, recent claims |
| `/documents` | Documents | Upload PDF/PNG/JPG/TIFF (≤ 50 MB), view OCR text, extract claim data, index for AI search |
| `/claims` | Claims | Server-side search and status filters (also reachable from the header search) |
| `/claims/:id` | Claim detail | Approve / reject / flag, run risk validation |
| `/rag-search` | AI Search | Natural-language RAG query interface |
| `/validation` | Validation | Flagged and high-risk claims, batch validation of pending claims |

Every page shows loading, empty and error states from the live API; there is no bundled demo data.
Responses generated by the backend's mock LLM (`"source": "mock"`) are labelled "Mock AI".

## Development

Requires Node.js 20.19 or newer (`.nvmrc` selects Node 24).

```bash
npm ci
cp .env.example .env.local   # then point VITE_API_URL at your backend
npm run dev                  # http://localhost:5173
npm run lint
npm test                     # Vitest, single run (npm run test:watch to watch)
npm run build                # production build → dist/
```

Tests mock the HTTP layer of the shared axios instance (`src/test/mockApi.js`), so they never
need a running backend.

## Environment

```env
VITE_API_URL=http://localhost:8000/api   # must include the /api prefix
```

For production, set `VITE_API_URL` in Vercel's environment variables to the backend URL
including `/api`, e.g. `https://your-backend.up.railway.app/api`.

## Deployment

Deployed via Vercel. The root `vercel.json` configures the monorepo build and the SPA rewrite:

```json
{
  "installCommand": "cd frontend && npm ci",
  "buildCommand": "cd frontend && npm run build",
  "outputDirectory": "frontend/dist"
}
```

CI (`.github/workflows/frontend-ci.yml`) runs lint, tests and the build on every push and
pull request that touches `frontend/`.
